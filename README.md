# CPL-Lab: C Programming Lab Assignments

This repository contains a collection of C programs created for the Computer Programming and Logic (CPL) lab. These assignments cover fundamental concepts of the C programming language, from basic arithmetic to searching algorithms.

## Lab Assignments

Here is a list of the programs included in this repository:

 1. **`1.CelciusToFahrenheit.c`**: A program to convert temperature from Celsius to Fahrenheit.

 2. **`2.Rectangle.c`**: Calculates the perimeter, area, and diagonal of a rectangle based on user input for its length and breadth.

 3. **`3.Swapping.c`**: Swaps the values of two integer variables using a temporary variable.

 4. **`4.Comparison-I.c`**: A simple program that compares two predefined integer values and prints which one is greater.

 5. **`5.Comparision-II.c`**: Finds the largest among three numbers provided by the user.

 6. **`6.SimpleInterest.c`**: Calculates the simple interest based on the principal amount, rate of interest, and time period.

 7. **`7.CompundInterest.c`**: Calculates the compound interest for a given principal, rate, and time.

 8. **`8.CalculatorUsingSwitch.c`**: A basic calculator that performs addition, subtraction, multiplication, or division using a `switch` statement.

 9. **`9.DaysInAMonth.c`**: Displays the number of days in a given month using a `switch` statement.

10. **`10.While.c`**: Demonstrates the use of a `while` loop to print numbers from 1 to 10.

11. **`11.Sum.c`**: Calculates the sum of the first 'n' natural numbers using a loop.

12. **`12.FibonacciSequence.c`**: Generates and displays the Fibonacci sequence up to a specified number of terms.

13. **`13.LinearSearch.c`**: Implements a linear search algorithm to find a specific value within an array.

14. **`14.Pattern.c`**: Prints a pyramid-like pattern of asterisks (`*`) based on a given number of rows.

15. **`15.BinarySearch.c`**: Implements the binary search algorithm to efficiently find a value in a sorted array.

## How to Use

To run any of these programs, you will need a C compiler (like GCC).

1. **Clone the repository:**

   ```
   git clone <your-repo-url>
   
   ```

2. **Navigate to the directory:**

   ```
   cd CPL-Lab
   
   ```

3. **Compile the desired file:**

   ```
   gcc -o output_filename your_program_name.c
   
   ```

   For example, to compile the Fibonacci sequence program:

   ```
   gcc -o fibonacci 12.FibonacciSequence.c
   
   ```

4. **Run the executable:**

   ```
   ./output_filename
   
   ```

   For the example above:

   ```
   ./fibonacci
   
   ```
